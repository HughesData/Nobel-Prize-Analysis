# Nobel Prize Analysis

## About This Project
I completed this guided DataCamp project to practice using Python to explore Nobel Prize winners from 1901 to 2023.

## Questions Explored
- Which gender and birth country appear most frequently among winners?
- Which decade had the highest proportion of US-born winners?
- Which decade and prize category had the highest proportion of female winners?
- Who was the first woman to win a Nobel Prize, and in which category?
- Which individuals or organizations won more than once?

## Tools Used
- Python
- pandas
- NumPy
- Jupyter Notebook

## Project Files
- `notebook.ipynb`: Python code for the analysis
- `data/nobel.csv`: Dataset used by the notebook

## Skills Practiced
- Filtering and grouping data
- Calculating counts and proportions
- Comparing trends across decades and categories
